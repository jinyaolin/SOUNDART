# 聲音的合成



聲音的基礎特性對於音樂創作、聲音設計和音訊工程等領域至關重要。聲音本質上是透過介質傳播的機械振動，其主要特性包括頻率、振幅、音色和時間。**頻率**決定了音高，通常以赫茲（Hz）為單位；**振幅**影響音量，與聲音的響度直接相關；**音色**由聲波的諧波結構決定，賦予聲音獨特的質感；**時間特性**如包絡線（ADSR）則影響聲音的動態變化。透過理解並操控這些特性，我們可以使用工具如 Pure Data 來合成和處理聲音，創造出豐富多樣的聲音效果，滿足各種創意需求。

使用 Pure Data 進行聲音合成和處理，能夠大幅提升聲音創作與設計能力。Pure Data（Pd）是一種開源的視覺化編程環境，專為即時聲音合成和數字信號處理而設計。通過拖放和連接各種對象，透過即時操控聲音的頻率、振幅、波形等特性，而無需撰寫複雜的程式碼。這種直觀的操作方式，使得聲音處理變得更加容易理解和上手。透過深入學習和實踐，可以創建自定義的聲音合成器、效果器，甚至是互動式的聲音應用，為音樂製作和聲音設計帶來無限可能。

## 7.1 動手之前：Pd 眼中的「聲音」是什麼

在 Pd 裡寫聲音，和在錄音軟體裡剪聲音是兩件事。錄音軟體處理的是「已經存在的聲音檔」，Pd 處理的是「每一秒鐘四萬四千一百個數字」。理解下面四件事，之後所有補丁都會變得好懂。

### 取樣率、位元深度、區塊

- **取樣率（Sample Rate）**：每秒鐘紀錄幾個數字。Pd 預設 44100 Hz，也就是一秒切成 44100 份。取樣率決定了能表現的最高頻率（約為取樣率的一半，稱為 Nyquist 頻率，44100 Hz 下約 22050 Hz）。
- **位元深度（Bit Depth）**：每個數字的精細度。Pd 內部一律用 32-bit 浮點數運算，範圍是 **-1 到 1**；超過 1 就會產生破音（clipping）。
- **區塊（Block）**：Pd 不是一個數字一個數字算，而是一次算 **64 個取樣點**（預設值）。這 64 個點叫一個 block。這也解釋了一件初學者常撞到的事——訊號的最小延遲單位是 64 個取樣點（約 1.45 毫秒），而不是 0。

### 兩種線：訊號線與訊息線

| | 訊息線（Message） | 訊號線（Signal） |
|---|---|---|
| 外觀 | 細線 | **粗線** |
| 資料 | 離散事件（bang、數字、list） | 連續數字流（每秒 44100 個） |
| 何時發生 | 有事才發生 | 只要 DSP 開著就不停發生 |
| 物件命名 | `[osc]`（無波浪號） | `[osc~]`（有波浪號） |

**波浪號 `~` 是 Pd 最重要的視覺約定**：看到 `~` 就代表這個物件在處理音訊。訊號線不能接進非訊號物件的輸入端（Pd 會直接報錯），反之亦然。

### 訊號會自動相加

這是 Pd 一個非常好用、但文件很少強調的規則：

> **當多條訊號線接到同一個 inlet 時，Pd 會自動把它們相加。**

所以「混音」不需要任何 mixer 物件——把三個 `[osc~]` 都接到同一個 `[*~]` 的左 inlet，它們就混在一起了。這也是下一節加法合成的基礎。

### DSP 開關與音量安全

Pd 開起來時 **DSP 是關的**，補丁接得再漂亮也不會有聲音。這是初學者第一名的「為什麼沒聲音」。

打開的方法有三種：

1. 主視窗右上角勾選 **DSP** 核取方塊
2. 選單 `Media → DSP On`（快捷鍵 Ctrl/Cmd + `/`）
3. 在補丁裡放一個訊息盒：`[; pd dsp 1(`，點它就開（`[; pd dsp 0(` 關）

```plaintext
[; pd dsp 1(      [; pd dsp 0(
```

> ⚠️ **戴耳機時請先做一件事**：任何音源到 `[dac~]` 之間，一定先經過一個 `[*~ 0.05]`。合成器很容易一不小心送出滿刻度訊號，而 `[osc~]` 的輸出是 -1 到 1 的**滿振幅**。先把音量壓到 5%，確認會響了再慢慢往上開。

## 7.2 最小可發聲的補丁

先把「會出聲」這件事做出來，再談合成。

```plaintext
[osc~ 440]          <- 產生 440 Hz 正弦波（振幅 -1 ~ 1）
|
[*~ 0.05]           <- 音量壓到 5%
|
[dac~]              <- 送到音效卡（左 inlet = 左聲道，右 inlet = 右聲道）
```

`[dac~]` 有兩個 inlet，分別是左右聲道。只接左邊就只有左耳有聲音——把 `[*~ 0.05]` 的 outlet **同時拉到 `[dac~]` 的兩個 inlet**，就會兩耳都有。

加上音高控制與開關，就是一個可用的測試台：

```plaintext
[tgl]                     [nbx]  <- 數字框，輸入頻率
|                          |
|                       [osc~ ]
|                          |
+---------------------> [*~ ]    <- tgl 輸出 0/1 當作靜音開關
                           |
                        [*~ 0.05]
                           |
                        [dac~ ]
```

> 這裡的 `[tgl]` 直接乘上訊號會產生「喀」一聲（下一節的包絡會解決）。先忍受它，第 7.6 節會處理。

## 7.3 加法合成（Additive Synthesis）

### 概念

十九世紀的傅立葉（Fourier）證明了一件事：**任何週期性的波形，都可以拆解成一堆不同頻率、不同振幅的正弦波相加**。加法合成就是反過來做——用一堆正弦波「疊」出想要的音色。

自然樂器的聲音之所以不是純正弦波，就是因為它同時發出**基頻（fundamental）**和一系列**泛音（harmonics）**。泛音的頻率通常是基頻的整數倍：

| 泛音 | 頻率（基頻 220 Hz） | 典型相對振幅 |
|---|---|---|
| 第 1（基頻） | 220 Hz | 1.0 |
| 第 2 | 440 Hz | 0.5 |
| 第 3 | 660 Hz | 0.33 |
| 第 4 | 880 Hz | 0.25 |

**泛音的相對強度決定音色**——這就是 2.1 節說的「音色由諧波結構決定」的具體意思。

### 補丁：手工做一個鋸齒波

理論上，鋸齒波 = 所有整數倍泛音，振幅為 1/n。用四個 `[osc~]` 近似它：

```plaintext
[nbx]  <- 基頻，例如 220
|
[t f f f f]                          <- trigger，把同一個數字送給四個振盪器
|      |        |         |
|   [* 2]    [* 3]     [* 4]
|      |        |         |
[osc~] [osc~]  [osc~]   [osc~]
|      |        |         |
[*~ 1] [*~ 0.5] [*~ 0.33] [*~ 0.25]  <- 每個泛音各自的振幅
|      |        |         |
+------+--------+---------+          <- 全部接到同一個 inlet，Pd 自動相加
       |
    [*~ 0.05]
       |
    [dac~ ]
```

注意 `[t f f f f]`（`[trigger float float float float]` 的簡寫）：它保證四個振盪器**依右到左的固定順序**收到同一個頻率值。這正是第 6 章「訊號物件的執行順序」在真實合成器裡的用途——沒有它，多路分接的順序是不確定的。

### 動手改改看

- 把 `[* 2]` 改成 `[* 2.01]`：泛音略微失諧，聲音會開始「活」起來（beating，拍音）。
- 把 `[* 2]` `[* 3]` `[* 4]` 改成 `[* 2.7]` `[* 5.1]` `[* 8.4]`：非整數倍泛音 → 鐘、鑼一類的**非諧波（inharmonic）**音色。
- 只留奇數倍泛音（1、3、5、7）：得到接近方波的音色，聽起來像單簧管。

> **加法合成的代價**：要做出豐富音色需要非常多個振盪器，CPU 負擔大、參數也多到難以控制。所以實務上更常用的是下一節的減法合成。

## 7.4 減法合成（Subtractive Synthesis）

### 概念

減法合成的思路和加法相反：**先做一個泛音很多的「粗胚」，再用濾波器把不要的頻率削掉**——像雕塑，從一整塊石頭把多餘的部分鑿掉。

這是類比合成器（Moog、Roland 等）的標準架構，也是最容易控制的合成方式：

```
音源（泛音豐富）→ 濾波器（削掉某些頻率）→ 放大器（決定音量隨時間的變化）
   OSC                 FILTER                      AMP
```

### 常用音源

| 物件 | 波形 | 泛音內容 |
|---|---|---|
| `[phasor~ 220]` | 鋸齒波（0~1） | 所有整數倍泛音，最豐富 |
| `[noise~]` | 白噪音 | 所有頻率都有，用來做風、海浪、打擊樂 |
| `[osc~ 220]` | 正弦波 | 只有基頻，**幾乎沒東西可以減**，不適合當減法音源 |

> `[phasor~]` 輸出的是 **0 到 1** 的上升斜坡，不是 -1 到 1。要當音源用通常會 `[-~ 0.5]` 把它移到中心（去掉直流偏移），否則會有一個固定的 DC offset 壓在訊號上。

### 常用濾波器

| 物件 | 類型 | 用法 |
|---|---|---|
| `[lop~ 1000]` | 低通（Low-pass） | 削掉 1000 Hz 以上，聲音變悶、變暖 |
| `[hip~ 300]` | 高通（High-pass） | 削掉 300 Hz 以下，去掉低頻轟隆 |
| `[bp~ 800 5]` | 帶通（Band-pass） | 只留 800 Hz 附近；第二個參數是 Q 值（越大越尖銳） |
| `[vcf~ 800 5]` | 可被訊號控制的帶通 | 中心頻率吃**訊號**輸入，可以做掃頻 |

`[lop~]` 和 `[hip~]` 是一階濾波器，斜率很緩（每八度 6 dB），聽起來溫和。想要更陡的效果就串接兩三個。

### 補丁：會呼吸的風聲

```plaintext
[noise~]                 <- 白噪音當粗胚
|
[bp~ 500 8]              <- 帶通，只留 500 Hz 附近
|                        ^
|                        |
|                     [osc~ 0.2]    <- 每 5 秒一次的極慢正弦波（LFO）
|                        |
|                     [*~ 300]      <- 擺盪幅度 ±300 Hz
|                        |
|                     [+~ 700]      <- 中心點移到 700 Hz（範圍變成 400~1000）
|                        |
|                    （接到 [vcf~] 的中間 inlet）
[*~ 0.3]
|
[dac~ ]
```

實作時把 `[bp~]` 換成 `[vcf~ 700 8]`，因為 `[bp~]` 的中心頻率只吃訊息、不吃訊號，沒辦法被 LFO 連續掃動；`[vcf~]` 的第二個 inlet 是**訊號 inlet**，可以直接接上面那條調變鏈。

**LFO（Low Frequency Oscillator，低頻振盪器）**是這裡的關鍵概念：一個頻率低到聽不見（通常 0.1～20 Hz）的振盪器，不拿來發聲，而是拿來**控制別的參數**。`[osc~ 0.2] → [*~ 300] → [+~ 700]` 這個「乘上幅度、加上中心點」的組合，是 Pd 裡把 -1~1 的訊號映射到任意範圍的標準寫法，之後會一直用到。

## 7.5 調變合成（Modulation Synthesis）

用一個訊號去改變另一個訊號的參數，就叫調變。上一節的 LFO 掃濾波器已經是調變了，只是速度慢。**當調變速度快到進入聽覺範圍（20 Hz 以上），就會產生全新的泛音**——這是調變合成的核心魔法。

### 振幅調變（AM）與環形調變（Ring Modulation）

兩者都是「把兩個訊號相乘」，差別只在調變訊號有沒有偏移到正值：

```plaintext
環形調變（Ring Mod）：兩個都是 -1~1 的雙極訊號
[osc~ 440]      [osc~ 137]
|                |
+----[*~ ]-------+          <- 直接相乘
        |
     [*~ 0.1]
        |
     [dac~ ]
```

相乘的結果會產生 **和頻與差頻**（440+137 = 577 Hz、440-137 = 303 Hz），原本的 440 Hz 反而消失了。因為和差頻通常不是整數倍關係，聽起來是金屬味、鐘聲味的非諧波音色——這是科幻電影機器人聲音的經典作法。

**振幅調變**則是把調變訊號先移成正值（`[*~ 0.5] → [+~ 0.5]`，範圍變 0~1），原本的載波頻率會保留下來，效果比較像顫音（tremolo）。

### 頻率調變（FM）

FM 是用調變訊號去改變載波的**頻率**。1973 年 John Chowning 在史丹佛發表了 FM 合成，1983 年 Yamaha DX7 把它變成史上最暢銷的合成器——整個 1980 年代流行樂的電鋼琴、貝斯、鐘聲，幾乎都是 FM。

```plaintext
[nbx]                     <- 載波頻率 fc，例如 220
|
[t f f]
|         |
|      [* 1]              <- 調變頻率 fm = fc × 比例（這裡設 1:1）
|         |
|      [osc~ ]            <- 調變振盪器
|         |
|      [*~ 500]           <- 調變深度（頻率偏移量，Hz）
|         |
+------[+~ ]              <- 載波頻率 + 偏移量
          |
       [osc~ ]            <- 載波振盪器（頻率吃左 inlet 的訊號）
          |
       [*~ 0.1]
          |
       [dac~ ]
```

FM 有兩個決定音色的關鍵參數：

- **比例（Ratio）= fm / fc**：整數比（1:1、2:1、3:2）產生諧波音色，聽起來像樂器；非整數比（1:1.41）產生非諧波音色，聽起來像鐘、鑼、金屬。
- **調變指數（Index）= 頻率偏移量 / fm**：控制泛音的**數量**。Index 越大，泛音越多、聲音越亮越尖。

實務上會把 `[*~ 500]` 的值接上一個包絡——**讓 Index 隨時間衰減**，就會得到「一開始很亮、然後變柔和」的效果，這正是真實樂器的行為（撥弦、敲擊的瞬間泛音最豐富）。這一招是 FM 合成聽起來「像真樂器」的最大祕密。

> **`[osc~]` 的左 inlet 同時接受訊息和訊號**：送數字進去是設定固定頻率，接訊號線進去則是連續調變頻率。上面補丁的 `[+~]` 輸出接到 `[osc~]` 左 inlet，走的就是後者。

## 7.6 包絡：讓聲音有開始與結束

前面所有補丁都有同一個毛病——用 `[tgl]` 或 `[*~ 1]` 直接開關，會聽到「喀」的一聲。原因是振幅**瞬間**從 0 跳到 1，這個垂直的跳變本身就含有全頻段的能量，也就是一次點擊噪音（click）。

解法是**包絡（Envelope）**：讓振幅在一小段時間內平滑地變化。

### ADSR

樂器聲音的音量隨時間變化，通常拆成四段：

| 階段 | 全名 | 意義 | 典型值 |
|---|---|---|---|
| **A** | Attack | 從 0 升到最大值要多久 | 鋼琴 5 ms、弦樂 300 ms |
| **D** | Decay | 從最大值掉到持續音量要多久 | 100 ms |
| **S** | Sustain | 按著不放時維持的音量（**這是音量不是時間**） | 0.6 |
| **R** | Release | 放開後衰減到 0 要多久 | 鋼琴 800 ms、管風琴 20 ms |

### `[line~]` 與 `[vline~]`

Pd 用 `[line~]` 產生線性斜坡訊號。它接受 `目標值 花費時間(毫秒)` 這樣的訊息：

```plaintext
[bang]
|
[t b b]
|      |
|   [1 10(          <- 10 毫秒內升到 1（Attack）
|      |
[300 500(           <- 延遲 300 ms 後，500 ms 內降到 0（Release）
   |   |
   +---+
       |
   [line~ ]         <- 產生平滑的振幅曲線
       |
[osc~ 440]--[*~ ]   <- 用包絡去乘音源
              |
           [*~ 0.3]
              |
           [dac~ ]
```

**`[vline~]` 比 `[line~]` 更適合做包絡**，理由有二：

1. **取樣點精度**：`[line~]` 的轉折只能發生在 block 邊界（64 個取樣點的倍數），`[vline~]` 可以精確到單一取樣點。做快速打擊樂時差別聽得出來。
2. **可以一次寫完整條包絡**：`[vline~]` 接受用逗號串起來的多段訊息，第三個數字是「延遲多久才開始這一段」。

一整條 ADSR 用 `[vline~]` 只要一個訊息盒：

```plaintext
[1 5, 0.6 100 5, 0 400 400(
 ↑         ↑          ↑
 5ms升到1   5ms後花100ms降到0.6   400ms後花400ms降到0
 (Attack)  (Decay→Sustain)      (Release)
|
[vline~ ]
```

> **經驗法則**：Attack 再短也不要設 0。給它 2～5 毫秒，click 就會消失，而人耳完全察覺不到這 5 毫秒。

## 7.7 取樣與波表

不是所有聲音都要從零合成。Pd 可以把音檔載進**陣列（array）**，再用各種方式播放它。

### 建立陣列並載入音檔

1. 選單 `Put → Array`，命名為 `mysound`
2. 用 `[soundfiler]` 讀檔（`-resize` 會自動把陣列調整成音檔長度）：

```plaintext
[read -resize sound.wav mysound(
|
[soundfiler]
|
[nbx]              <- 輸出音檔的取樣點總數，之後會用到
```

### 三種播放方式

| 物件 | 用途 | 特性 |
|---|---|---|
| `[tabplay~ mysound]` | 直接播放 | 最簡單，原速播放，收到 bang 就從頭播 |
| `[tabread4~ mysound]` | 依索引讀取 | 吃一個「位置訊號」，**可以變速、倒放、凍結** |
| `[readsf~]` | 從硬碟串流 | 不佔記憶體，適合很長的音檔 |

`[tabread4~]` 是最有創作彈性的一個。它的輸入是「現在要讀陣列的第幾個取樣點」，所以只要餵不同的位置訊號，就能做出各種效果：

```plaintext
[nbx]              <- 播放速度倍率，1 = 原速
|
[*  ]              <- 乘上「原速需要的頻率」= 取樣點總數 / 44100 的倒數
|
[phasor~ ]         <- 0~1 的循環斜坡
|
[*~ 88200]         <- 乘上陣列總長度 → 變成 0~總長度 的位置訊號
|
[tabread4~ mysound]
|
[*~ 0.3]
|
[dac~ ]
```

改 `[phasor~]` 的頻率就是改播放速度（同時也會改音高，像轉盤加速）；給負的頻率就是**倒放**；把 `[phasor~]` 換成一個固定數字（`[sig~ 30000]`），就會停在某一點無限重複那一小段——**凍結**，這是聲音藝術裡很常用的手法。

> **為什麼是 `tabread4~` 而不是 `tabread~`？** 結尾的 4 代表四點內插（cubic interpolation）。播放位置通常落在兩個取樣點之間，沒有內插的 `[tabread~]` 會直接取整數，產生明顯的雜訊。**做音訊播放一律用 `[tabread4~]`。**

## 7.8 效果器：延遲家族

延遲是所有時間類效果的基礎。Pd 的延遲要用**一對**物件：

- `[delwrite~ 名稱 最大毫秒數]`：開一塊延遲緩衝區，把訊號寫進去
- `[delread~ 名稱 毫秒數]`：從緩衝區的某個時間點讀出來（延遲時間固定）
- `[delread4~ 名稱]`：同上，但延遲時間吃**訊號**，可以連續改變（舊名 `[vd~]`）

### 回聲（Echo）

```plaintext
[音源]
|
+---------------------+
|                     |
[delwrite~ buf 2000]  |   <- 開 2 秒的緩衝區
                      |
[delread~ buf 375]    |   <- 讀 375 毫秒前的訊號
|                     |
[*~ 0.6]              |   <- 回授量，務必 < 1
|                     |
+---> 接回 [delwrite~ buf 2000] 形成回授
|
+---> [*~ 0.3] --- [dac~ ]
```

> ⚠️ **回授量一定要小於 1**。等於或大於 1 時音量會無限累積，幾秒內就會炸掉喇叭和耳朵。第一次接回授時，先把 `[*~]` 的值設 0.3，確認會衰減再往上調。

### 從延遲長出來的效果

同一組物件，只要改延遲時間的長短與是否調變，就是完全不同的效果：

| 效果 | 延遲時間 | 是否調變 | 聽感 |
|---|---|---|---|
| **梳狀濾波（Comb）** | 1～10 ms | 否 | 音色染色、金屬感 |
| **鑲邊（Flanger）** | 1～10 ms | 是（LFO 慢速掃） | 噴射機掠過的呼嘯 |
| **合唱（Chorus）** | 20～40 ms | 是（隨機微幅） | 變厚、變寬，像很多人一起唱 |
| **回聲（Echo）** | 100 ms 以上 | 否 | 聽得出來是重複 |

要做 Flanger，把上面補丁的 `[delread~ buf 375]` 換成 `[delread4~ buf]`，再接一條 LFO 進去控制延遲時間：

```plaintext
[osc~ 0.3]        <- 0.3 Hz 的慢速 LFO
|
[*~ 3]            <- 擺盪 ±3 ms
|
[+~ 5]            <- 中心 5 ms（範圍 2~8 ms）
|
[delread4~ buf]
```

### 殘響（Reverb）

殘響本質上是幾百個不同時間的延遲疊加，模擬聲音在空間裡的反射。自己接太麻煩，Pd vanilla 內建三個現成的：

| 物件 | 說明 |
|---|---|
| `[rev1~]` | 單一脈衝殘響，參數少、好上手 |
| `[rev2~]` | 較細緻的可調殘響 |
| `[rev3~]` | 立體聲輸出，音質最好 |

（PlugData 與 Pd-extended 另外提供 `[freeverb~]`，音色更接近商業殘響器。）

## 7.9 顆粒合成（Granular Synthesis）初探

顆粒合成把聲音切成幾十毫秒的極短片段（grain），再用大量重疊播放的方式重組。因為每顆 grain 的**位置、長度、音高、音量**都可以獨立亂數決定，它能做出「把一秒的聲音拉長成三分鐘而不變調」這種在其他合成法裡辦不到的效果——聲音藝術與環境音樂大量使用它。

最小的實作邏輯是：

1. 用 `[metro 20]` 每 20 毫秒觸發一顆 grain
2. 每次觸發時用 `[random]` 決定要從陣列的哪個位置開始讀
3. 每顆 grain 用 `[vline~]` 套一個很短的包絡（避免頭尾的 click）
4. 用 `[poly]` 或多個複製的子補丁讓 grain 彼此重疊

完整實作需要用到子補丁（subpatch）與 `[clone]`，超出本章範圍，但建議在熟悉 5.6 的包絡與 5.7 的 `[tabread4~]` 之後回頭挑戰——那時你會發現顆粒合成不過是「包絡 + 陣列讀取」重複幾十次而已。

## 7.10 除錯：沒聲音的時候檢查什麼

按順序檢查，九成的問題在前三項：

1. **DSP 開了嗎？** 主視窗右上角的 DSP 核取方塊。
2. **接到 `[dac~]` 了嗎？兩個 inlet 都接了嗎？** 只接左邊只有左耳有聲音。
3. **音量是不是 0？** 檢查所有 `[*~]` 的值。`[*~]` 沒給參數時預設是 **0**，等於靜音。
4. **Pd 主控台（Pd window）有紅字嗎？** `... couldn't create` 代表物件名稱打錯或該外掛未安裝。
5. **訊號線接到訊息 inlet 了嗎？** 主控台會出現 `signal outlet connect to nonsignal inlet`。
6. **音效卡設定對嗎？** `Media → Audio Settings`，確認輸出裝置與取樣率。
7. **爆音／破音**：訊號超過 ±1。在 `[dac~]` 前加一個 `[clip~ -1 1]` 當保險，並回頭降低各級 `[*~]` 的值。
8. **有低頻轟隆或喇叭鼓動**：直流偏移（DC offset）。用了 `[phasor~]` 當音源卻沒 `[-~ 0.5]`，或包絡沒回到 0。在輸出前串一個 `[hip~ 5]` 可以濾掉。

### 物件名稱正名對照

初學教材（包含網路上很多文章，以及本教材第 6 章的部分列表）常寫出**實際上不存在**的物件名稱。以下是 Pd vanilla 的正確寫法：

| 常見誤寫 | 正確物件 | 說明 |
|---|---|---|
| `[delay~]` | `[delwrite~]` + `[delread~]` / `[delread4~]` | `[delay]`（無 `~`）確實存在，但那是延遲**訊息**用的，不能延遲音訊 |
| `[reverb~]` | `[rev1~]` / `[rev2~]` / `[rev3~]` | vanilla 沒有叫 `reverb~` 的物件 |
| `[button]` | `[bng]` | 選單是 `Put → Bang` |
| `[toggle]` | `[tgl]` | 選單是 `Put → Toggle` |
| `[slider]` / `[hslider]` | `[hsl]` / `[vsl]` | 水平／垂直滑桿 |
| `[number]` | 數字框（`Put → Number`）或 `[nbx]` | `[nbx]` 是 IEM 版的數字框 |

> 這些 UI 物件通常直接從 `Put` 選單放置，很少手打名稱，所以打錯不易被發現。但寫進補丁檔或教學文件時，名稱要對。

## 7.11 練習

由淺入深，每題都可以在 30 分鐘內完成：

1. **警報器**：用 `[osc~]` 加一個 0.5 Hz 的 LFO 掃頻率，做出救護車的聲音。提示：`[osc~ 0.5] → [*~ 200] → [+~ 800] → [osc~]`。
2. **無 click 的節拍器**：用 `[metro 500]` 觸發 `[vline~]` 包絡（Attack 3 ms、Release 80 ms）去乘 `[osc~ 1000]`。
3. **風聲**：`[noise~]` 經 `[vcf~]`，中心頻率用兩個不同速度的 LFO 相加去掃，做出有起伏的風。
4. **FM 電鋼琴**：比例設 1:1，把調變深度接上一條 400 ms 衰減的包絡，聽聽看是不是有 DX7 的味道。
5. **凍結取樣**：載入一段自己的錄音，用 `[tabread4~]` + `[sig~]` 停在某一點，然後用滑桿慢慢移動那個點。
6. **綜合**：把第 4 題的 FM 音源送進第 7.8 節的 Flanger 與 `[rev3~]`，做出一個完整的「音源 → 效果 → 輸出」訊號鏈。

## 小結

這一章的所有內容其實只有一句話：**聲音合成就是「產生一個數字流，然後不斷改變它」**。

- 產生：`[osc~]`、`[phasor~]`、`[noise~]`、`[tabread4~]`
- 改變振幅：`[*~]`，配合 `[line~]` / `[vline~]` 做包絡
- 改變頻率內容：濾波器（減法）、疊加（加法）、相乘與 FM（調變）
- 改變時間：`[delwrite~]` / `[delread4~]` 家族與殘響

真正的差別不在於你會不會用這些物件，而在於**你用它們去追什麼聲音**。技術部分到這裡已經夠用了；剩下的是回到第 1、2 章講的那些——你想讓聽的人聽見什麼。
