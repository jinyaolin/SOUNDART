# 兩個工具的比較與選擇

## 到底該用哪一個

第 9 章

---

## 先說結論

> ## 先學 Pure Data。
>
> 免費、跨平台、原理最裸露，而且能嵌進別的東西裡。
> **等你遇到 Pd 做不到的事，再去學 Max——那時候你只需要一個下午。**

**理由**：兩個工具的核心心智模型是同一個（同一個人設計的）。
真正花時間的是「訊號與訊息」「hot / cold」「右到左」「`~` 的分界」，
那些在哪一邊學都一樣。

--

## 除非你符合這幾項

- 學校／單位已經買了授權，同學都在用
- 你的作品**一定會用到影像**（Jitter 遠比 GEM 成熟）
- 你已經是 Ableton Live 使用者，想做 Max for Live
- 你要接的硬體有現成的 Max 支援套件

→ 那就直接學 Max，比較省事。

---

## 逐項比較

| 面向 | Pure Data | Max/MSP |
|---|---|---|
| 授權 | **免費開源** | 商業，需購買 |
| 學習資源 | 少而分散 | **多，說明檔可執行** |
| 內建物件 | 少而精 | **多，品質一致** |
| 影像／3D | GEM（外掛） | **Jitter（內建成熟）** |
| **音訊品質** | 相同 | 相同 |
| 可嵌入性 | **libpd / hvcc** | RNBO（較新） |
| DAW 整合 | PlugData（VST3） | **Max for Live** |
| 檔案格式 | **純文字，可 git diff** | JSON，難 diff |
| 長期保存 | **開源，二十年後還開得起來** | 依賴商業公司 |

---

## 三個常見的誤解

**「Max 的音質比較好」**——不是。
兩者都是 32-bit 浮點、同樣的演算法。差別在**內建工具的多寡**，不在聲音。

**「Pd 比較難」**——不完全對。
Pd 的難來自資源少、物件少（很多要自己接）。但也因此你會更清楚它在做什麼。

**「學了一個就白費另一個」**——完全不會。

---

## 五個真實情境

**展場互動裝置** → **Max**，除非預算是零
（Jitter、`[serial]`、Presentation Mode，出問題有人幫你）
但若要**長期典藏**，Pd 的開源特性反而是優勢

**手機 App／遊戲／塞進硬體** → **Pd，沒有第二個選擇**
libpd 進 Unity／Unreal；hvcc 編成 C 跑在 Raspberry Pi、Bela、Daisy

--

## 五個真實情境（續）

**課堂教學** → **Pure Data（PlugData）**
全班零成本、跨平台一致。而且物件少反而是好事——
沒有現成的 `[adsr~]`，學生就得自己用 `[vline~]` 拼出包絡，於是他真的懂了。

**現場演出** → 兩者都行
用 Ableton 當骨幹 → Max for Live；要獨立的黑盒子 → Pd

**學術研究** → **Pure Data**
開源代表**可重現**：審查者能真的打開你的補丁重跑一次

---

## 你真正在學的東西

換工具時，這些**一個字都不用重學**：

- `~` 代表音訊
- 訊號線比較粗，訊息線比較細
- 最左邊是 hot inlet，其他是 cold
- 一個 outlet 接多個目標時**從右到左**
- 多條訊號接同一個 inlet 會**自動相加**
- 用 `[t]` 明確指定順序
- 子補丁與抽象、`[send]` / `[receive]`
- 合成原理（加法／減法／FM／取樣／延遲）

> ### 這九條佔了你學習時間的九成。
> 剩下那一成是物件名稱——查表就好。

---

## 檔案能不能互通？

不能直接互通，但有幾條路。

- Pd 補丁不能在 Max 裡開，反之亦然——格式與物件集都不同
- **`cyclone`** 把許多 Max 物件名帶進 Pd，方便移植概念
- **PlugData** 讓 Pd 補丁以 VST3 在任何 DAW 裡跑
- **`hvcc`（Heavy）** 把 Pd 補丁編譯成 C／JS／外掛

> **實務上，你移植的是想法而不是檔案。**
> 重接一次通常比找轉換工具快。

---

## 什麼時候該離開這兩個工具

| 情況 | 建議 |
|---|---|
| 補丁大到你自己看不懂 | **SuperCollider**、Csound（文字、可寫迴圈） |
| 需要逐取樣點的極高效率 | Max 的 `gen~`、Pd 的 `expr~`，或直接寫 C++ |
| 要在瀏覽器裡跑 | Web Audio API、WebPd、RNBO 匯出 |
| 要做成商業外掛 | JUCE，或 RNBO／hvcc 匯出 |
| **只是要做音樂** | **老老實實用 DAW** |

> 最後一項最重要。這兩個工具的價值在於**做出別的軟體裡不存在的東西**。
> **如果 Ableton 三分鐘就能做完，那就用 Ableton。**

---

## 小結

> ### 選工具的順序應該是：
> ### 先確定作品要什麼，再回頭選工具。

反過來做——先愛上一個工具，再找題目給它做——是初學者最常見的陷阱。

1. 免費、要嵌入、要教學、要可重現 → **Pure Data**
2. 要影像、要接硬體、要交付給別人操作、要進 Ableton → **Max/MSP**
3. 兩個都學一點的成本，比你以為的低很多
